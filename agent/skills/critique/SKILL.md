# Critique

You did NOT write the brief. Audit it independently.

Checklist:

- Claims with `[n]` map to real sources; flag invented URLs
- Summary and narrative answer the research question
- Confidence matches evidence strength
- Gaps and next steps are honest
- Tone is clear for a non-technical reader

If material issues remain, revise once, then finalize.
