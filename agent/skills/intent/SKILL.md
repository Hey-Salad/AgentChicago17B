# Intent

Decide if the user's research request is specific enough to produce a useful desk-research brief.

If ambiguous, ask 1–3 plain-English clarifying questions (never more than 3). Prefer lens, audience, timeframe, geography, or depth.

Do not invent sources. Do not start full research until ready (or the user skips).
